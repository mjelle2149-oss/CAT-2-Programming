WEEK 3 - C PROGRAMS

This folder contains 16 source programs and their compiled Linux executables (.linux).

The programs follow the Week 3 uploaded materials:
- Programs 1-10: the Week 3 C conversion program set (also supplied in C++ form).
- Programs 11-16: practical-session exercises covering logical operators, nested conditions,
  if-else versus switch menus, plus/minus grading, and the multiple-student challenge.

Compilation performed with gcc using C11.
All 16 source files compiled successfully.
All 16 executables were launched with representative sample inputs successfully.
This is a smoke test, not exhaustive testing of every possible input.

IMPORTANT:
The included .linux files are Linux executables. They are NOT Windows .exe files.
To create Windows .exe files on your Windows computer:
1. Install MinGW-w64 and ensure gcc is available in PATH.
2. Open this folder.
3. Double-click COMPILE_WINDOWS.bat.
The script creates a separate .exe for each source file.

To run a Linux executable from a terminal: ./01_pass_fail.linux
