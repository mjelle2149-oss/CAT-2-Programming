WEEK 10 – C++ PROGRAMS ONLY
===========================

Activities (in the lecturer's order)
1. file_io_basics.cpp       - Read numbers.txt, calculate the sum, write sum.txt.
2. unhandled_error.cpp      - Demonstrate the effect of not checking a missing input file.
3. return_vs_exception.cpp - Compare return-code handling with try/throw/catch.
4. robust_csv.cpp           - Read student CSV records and skip malformed scores.

Files included
- Four .cpp source files.
- Four precompiled Linux executables (.linux).
- numbers.txt and students.csv sample input files.
- sum.txt output generated by Activity 1.
- COMPILE_WINDOWS.bat to build Windows .exe files.

How to run on Windows (VS Code terminal)
1. Install MinGW-w64 and ensure g++ is on PATH.
2. Extract this ZIP into one folder.
3. Open that folder in VS Code.
4. Run COMPILE_WINDOWS.bat, or compile each file with:
   g++ -std=c++17 file_io_basics.cpp -o file_io_basics.exe
5. Run the executable from the same folder so it can find the text/CSV input files.

Important
- The included .linux files are Linux executables and will not run natively on Windows.
- COMPILE_WINDOWS.bat creates actual Windows .exe files on your laptop.
- Activity 2 intentionally omits the file-open check to demonstrate the lesson.
- Activity 3 uses data.txt as a deliberately missing file to demonstrate both strategies.
- Activity 4 uses the exact sample records from the practical. Charlie's invalid score is skipped.
