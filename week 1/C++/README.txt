WEEK 1 - C++ PROGRAM
=======================

Exercise: About Me - Interactive Program

This program asks the six questions from the Week 1 practical and displays
the student's profile summary.

Files:
- about_me.cpp: Source code.
- about_me: Compiled Linux executable.
- sample_run_output.txt: Output from a successful sample run.
- COMPILE_AND_RUN_WINDOWS.bat: Compiles and runs the program on Windows
  when the appropriate MinGW-w64 compiler is installed and available on PATH.

Compilation on Windows:
- C:   gcc about_me.c -o about_me.exe
- C++: g++ about_me.cpp -o about_me.exe

Run on Windows:
- about_me.exe

Run the included Linux executable:
- ./about_me

Verification:
- Compiled successfully with no compiler warnings.
- Executed successfully with six sample answers.
- Confirmed all six answers appear in the profile summary.

Note: The included executable is for Linux. The Windows batch file creates
a native Windows .exe on a Windows computer with MinGW-w64 installed.
